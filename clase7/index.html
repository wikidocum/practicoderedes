3. Configuración RIPv2 en Cisco

1. Configuración básica para resolución TP N°7

Preparar el Router: 

enable
configure terminal
hostname NOMBRE
enable secret redes2

Configurar las IPs de las interfaces: 

interface INTERFAZ
ip address IP MASCARA
no shutdown
exit

Verificar la configuración básica: 

show ip interface brief
show ip route

2. Configuración de RIPv2

configure terminal
 router rip
 version 2
 no auto-summary
 network RED1
 network RED2
 exit
end

El comando network no crea una ruta hacia esa red. Indica al proceso RIP qué redes directamente conectadas deben participar del protocolo.

A partir de esa información, los routers intercambian información y pueden aprender las redes remotas de otros routers.

4. Configuración OSPF en Cisco

1. Configuración básica para resolución TP N°7

Eliminar RIP: 

configure terminal
no router rip
end

Verificar la configuración básica: 

show ip interface brief
show ip route

2. Configuración de OSPF

configure terminal
router ospf 1
network RED1 WILDCARD area 0
network RED2 WILDCARD area 0
exit
end

A partir de esa información, los routers intercambian información y pueden aprender las redes remotas de otros routers.

3. Verificación de OSPF

show ip ospf neighbor

show ip route

show ip protocols

Resumen de la clase

En esta clase estudiamos el ruteo dinámico y su diferencia con el ruteo estático. Analizamos el funcionamiento de RIPv2 y OSPF, sus diferentes métricas y la forma en que los routers pueden adaptar sus rutas ante cambios en la topología.

Conclusión

El ruteo dinámico permite que una red pueda adaptarse a cambios sin depender de la modificación manual de cada ruta. RIP y OSPF utilizan diferentes mecanismos y métricas para seleccionar los caminos, y la convergencia permite que los routers actualicen sus tablas cuando se produce una falla.
